# Awesome DESIGN.md reference library

This folder is a copied, non-executable reference collection from `VoltAgent/awesome-design-md`. It is not a Codex skill and is not loaded automatically as instructions.

Use it when exploring visual patterns for EduCloud. Select a relevant reference, compare its layout principles and component guidance with the EduCloud visual direction, and then create an original implementation. Do not copy brand assets, logos, mascots, wording, or distinctive branded screens.

EduCloud’s active product direction is documented in:

- `EDU_CLOUD_VISUAL_DIRECTION.md`
- `ANDROID_UI_UX_SCREEN_PLAN.md`
- `design-references/subway/`

The collection’s original README is at `README.md`. Many entries link to external DESIGN.md documents rather than including the full documents locally.
